# OIBSIP — Data Science Portfolio

A parallel portfolio of five reproducible projects covering classification, EDA, regression, NLP, and model evaluation.

## Projects
1. Iris Flower Classification — Logistic Regression and KNN
2. Unemployment Analysis in India — regional and temporal EDA
3. Used Car Price Prediction — preprocessing and regression
4. SMS Spam Detection — TF-IDF NLP classification
5. Advertising Sales Prediction — regression and feature impact

Each project includes a notebook, README, requirements, and reproducible run instructions.
